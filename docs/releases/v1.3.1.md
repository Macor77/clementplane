# Clementplane V1.3.1 — Installation et mises à jour mobiles

Une installation réalisée depuis une adresse de déploiement temporaire peut conserver une ancienne version. Le parcours d’installation de Clementplane dirige désormais vers **https://app.clementplane.fr** avant toute installation depuis une autre adresse.

- Installation Android et aide iPhone conservées sur l’adresse officielle.
- Liens de connexion et de désabonnement des e-mails de nouveautés fixés côté serveur, y compris pour les anciens clients d’administration.
- Aide d’installation et FAQ complétées pour remplacer une ancienne icône une seule fois ; données du compte conservées.
- Aucun changement des missions, des bilans, des agendas ou des droits. Aucune migration SQL.

Une ancienne application figée sur une autre origine ne peut pas recevoir ce correctif automatiquement. Un message d’accompagnement est préparé, non envoyé. Preuves de livraison : [dossier de clôture](../sprints/pwa-official-installation/CLOSURE.md).
