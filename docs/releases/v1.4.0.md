# V1.4.0 — candidat, non publié

Les formateurs peuvent détailler leurs frais dans le bilan de mission : onze catégories, plusieurs lignes d’une même catégorie, précision facultative sauf Autres frais, et total automatique. Ajout, modification et suppression s’enregistrent avec le bilan.

Les anciennes saisies sont conservées et reprises sans duplication. Les frais restent privés, comme le kilométrage et les difficultés. Aucun calcul kilométrique, justificatif ou changement de Mes statistiques.

Migration additive requise avant publication du frontend ; ancienne PWA à actualiser pour enregistrer un bilan. Déploiement, tag et release de production attendent la validation explicite de Vincent. Dossier : docs/sprints/v1.4.0/.
