# Clementplane V1.4.0 — frais détaillés du formateur

Publiée le 15 novembre 2026 après validation et autorisation de Vincent.

Dans le bilan de mission, les formateurs saisissent leurs dépenses ligne par ligne : onze catégories, montant et précision facultative sauf « Autres frais ». Une même catégorie peut se répéter. Les lignes s’ajoutent, se modifient et se suppriment ; le total se calcule automatiquement en centimes et accepte zéro.

Les anciennes saisies sont conservées et reprises sans duplication. Un ancien texte sans montant reste disponible et signalé comme incomplet. Les dépenses, leur total, les kilomètres réels et les difficultés restent privés. Aucun justificatif, calcul d’indemnité kilométrique ou transmission aux agendas.

Les autres champs du bilan et l’interface Mes statistiques restent inchangés. La structure prépare de futures statistiques de dépenses, à développer séparément.

Migration additive 20261115114709 appliquée avant l’application. Les anciennes PWA doivent actualiser pour enregistrer les bilans au nouveau format. Recette : 389 unitaires, 53 parcours navigateur, SQL local et hébergé ; données antérieures et droits contrôlés en production. Tests navigateur avec API simulées, pas de saisie réelle en production ni de test sur appareil installé.

La release joint les sources complètes du commit tagué, sans secrets ni dépendances installées, avec manifeste et SHA-256 ; téléchargement et intégrité contrôlés par le workflow. Dossier de clôture : docs/sprints/v1.4.0/. Aucun message utilisateur envoyé.
