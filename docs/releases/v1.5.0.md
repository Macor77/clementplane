# Clementplane V1.5.0 — Apprenants partiellement formés

Le bilan de mission dispose d’un volet **Apprenants partiellement formés**, fermé par défaut. Ajoutez autant de lignes que nécessaire pour indiquer le nombre de personnes et la durée suivie en jours et/ou heures.

Ces personnes sont **incluses dans le total des apprenants effectivement formés**. Le détail ne crée aucun groupe supplémentaire et n’ajoute pas ses durées au temps animé par le formateur. Le nombre de sessions et les statistiques gardent leur comptage actuel.

Ajout, modification, suppression et rechargement des lignes ; contrôle du sous-total et des durées ; sauvegarde atomique avec les autres champs du bilan. Les frais, kilomètres et difficultés restent privés. L’OF commanditaire consulte le détail de réalisation en lecture seule. Aucun événement d’agenda ni message envoyé.

Migration additive : les bilans existants sont conservés, avec un détail vide. Les anciennes applications ne peuvent pas effacer un détail qu’elles ne savent pas éditer ; actualiser Clementplane avant de compléter ce nouveau volet.

Validation : 406 tests unitaires, 58 tests navigateur avec API simulée (desktop/tablette/mobile), tests PostgreSQL réels en démonstration et contrôles non destructifs de production. Appareil/PWA installé non testé. Les anciens bilans multigroupes restent correctibles selon leur structure historique ; ce nouveau volet concerne les bilans à un groupe.
