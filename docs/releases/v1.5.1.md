# Clementplane V1.5.1 — Bilan compact et aides contextuelles

Le bilan est plus léger à parcourir, particulièrement sur mobile. Les boutons **« ? »** donnent accès à toutes les explications ; la fenêtre se referme pour reprendre la saisie. Sur mobile, l’aide s’ouvre en bas de l’écran. Confidentialité, intitulés, unités et rappel du total des apprenants restent visibles.

Ouvrir et fermer une aide conserve le brouillon, sans l’enregistrer. Les messages d’erreur et les avertissements liés aux données restent affichés. Dans le scénario mobile comparé, la hauteur de page diminue de 18,7 %.

Aucun changement des données, calculs, statistiques ou permissions ; aucune migration. Actualiser Clementplane pour profiter de cette présentation.

Validation : 406 tests unitaires et 63 parcours navigateur réussis ; captures ordinateur, tablette et mobile contrôlées. API simulée et mobile émulé, pas de test sur appareil physique. Version servie et routes de production vérifiées sans écriture de données réelles. Publication explicitement autorisée le 16 novembre 2026, [PR #26](https://github.com/Macor77/clementplane/pull/26).

Preuves : `docs/sprints/v1.5.1/`. Le ZIP joint contient les sources exactes du commit tagué, les captures fictives, un manifeste et un fichier SHA-256 ; aucun secret ni donnée métier privée. Aucun e-mail de nouveautés envoyé.
