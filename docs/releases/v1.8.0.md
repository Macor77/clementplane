# V1.8.0 · Dossier professionnel du formateur

**Version candidate, ouverture en attente.** Le formateur peut préparer plusieurs justificatifs d’un même type, suivre les échéances, partager une sélection à ses OF ou inviter une boîte e-mail. L’OF consulte et télécharge uniquement les pièces partagées. Seul le formateur gère les fichiers de son propre dossier.

Le remplacement conserve les accès existants et laisse le formateur choisir s’il prévient certains destinataires. L’ancienne version reste dans son historique privé pendant 30 jours. Les téléchargements antérieurs restent chez leurs destinataires.
