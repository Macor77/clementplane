**Objet : Clementplane sur votre téléphone : vérifiez l’accès aux nouveautés**

Bonjour,

Si vous avez installé Clementplane sur votre téléphone il y a quelque temps, votre ancienne icône peut encore ouvrir une version qui ne reçoit plus les nouveautés.

Pour vérifier, ouvrez **https://app.clementplane.fr** dans Chrome sur Android ou Safari sur iPhone, puis connectez-vous avec votre compte habituel. Vous pouvez notamment créer vos propres missions depuis « Mes missions » et accéder aux bilans et statistiques de vos formations.

Si ces fonctions apparaissent sur le site officiel mais pas dans votre application installée, remplacez cette ancienne installation une seule fois :

1. Vérifiez que vos saisies en cours sont enregistrées, puis désinstallez l’ancienne application Clementplane.
2. Revenez sur **https://app.clementplane.fr** dans votre navigateur et connectez-vous avec votre compte habituel.
3. Sur Android, utilisez « Installer Clementplane » ou le menu de Chrome, puis « Installer l’application » / « Ajouter à l’écran d’accueil ». Sur iPhone, utilisez Safari : Partager, « Sur l’écran d’accueil », puis « Ajouter ».

Vos missions et informations déjà enregistrées sur votre compte sont conservées. Une fois l’application installée depuis l’adresse officielle, vous n’avez pas à la réinstaller à chaque nouvelle fonctionnalité.
