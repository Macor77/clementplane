# Renseigner les frais d’une mission

Dans Bilan de la mission, ouvrez la rubrique « Privé — vous uniquement ».

1. Cliquez sur « + Ajouter une dépense ».
2. Choisissez la catégorie et saisissez le montant en euros, avec une virgule ou un point (deux décimales maximum). Zéro est accepté.
3. Ajoutez une précision si utile. Elle est obligatoire pour « Autres frais ».
4. Répétez pour chaque dépense : plusieurs repas, billets ou péages peuvent avoir la même catégorie. Supprimez une ligne avec son bouton « Supprimer ».
5. Vérifiez le total automatique puis cliquez sur « Enregistrer le bilan ». Attendez « Bilan enregistré » avant de quitter.

Les lignes entièrement vides sont ignorées ; les lignes partiellement remplies demandent une correction. Le kilométrage reste une saisie indépendante, sans calcul d’indemnité. La distance indicative de Clementplane est à vol d’oiseau et ne donne pas le trajet routier réel.

Les anciennes dépenses sont reprises dans une ligne « Autres frais ». Le volet « Ancienne saisie conservée » permet de retrouver le texte et le montant d’origine, sans les compter une deuxième fois. Une ancienne dépense sans montant est signalée : vous pouvez la compléter, la supprimer ou la conserver pendant une modification d’un autre champ.

Les frais, leurs précisions, le kilométrage et les difficultés restent réservés au formateur. Aucun justificatif n’est demandé, aucun e-mail ni événement d’agenda n’est envoyé. Les statistiques des dépenses viendront dans un développement ultérieur.
