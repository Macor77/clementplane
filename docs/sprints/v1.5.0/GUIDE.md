# Renseigner une participation partielle

1. Saisir le nombre total d’apprenants effectivement formés, en incluant les personnes partiellement formées.
2. Ouvrir le volet **Apprenants partiellement formés** dans Réalisation de la formation.
3. Ajouter une ligne pour les personnes ayant suivi la même durée. Exemple : **1 apprenant, 1 heure**, puis **3 apprenants, 3 heures**. Ces quatre personnes sont déjà dans le total.
4. Renseigner les jours et heures connus, sans multiplier la durée par l’effectif. Au moins une durée par ligne.
5. Enregistrer le bilan. Les lignes se rechargent à la prochaine visite, dans le volet fermé par défaut.

Modifier ou supprimer une ligne est possible. Les durées des lignes ne changent pas le temps animé par le formateur ni le nombre de sessions. L’OF commanditaire peut consulter ce détail en lecture seule ; les frais, kilomètres et difficultés restent privés.
