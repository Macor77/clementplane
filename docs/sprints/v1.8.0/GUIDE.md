# Utiliser le dossier professionnel

**Formateur.** Ouvrez « Mon dossier professionnel », puis « Déposer un document ». Choisissez un PDF simple, une image JPEG/PNG ou prenez une photo avec votre téléphone. Le type propose un intitulé modifiable. Indiquez la date connue ou choisissez « À renseigner » ou « Sans date d’expiration ». Deux certifications du même type peuvent coexister. Une note personnelle reste dans votre espace. Après une coupure, gardez le formulaire ouvert et réessayez.

**Partager.** Dans « Mes partages », choisissez un de vos OF ou une adresse e-mail. Cochez les pièces souhaitées, ou sélectionnez toutes les pièces présentes. Lisez la liste, le destinataire et la fin d’accès avant de confirmer. Les pièces ajoutées ultérieurement resteront privées. Les membres habilités d’un organisme reçoivent un accès en lecture et téléchargement. Une invitation e-mail vérifie l’accès à la boîte, qui peut être partagée.

**Remplacer.** Ouvrez « Gérer le document » puis « Remplacer ce document ». Les destinataires affichés obtiendront la nouvelle version. Pour prévenir certains d’entre eux, activez l’option e-mail et cochez leurs noms. L’ancienne version est consultable par vous pendant 30 jours. Pour couper l’accès à une pièce déjà envoyée, retirez le partage concerné, puis partagez de nouveau les pièces à conserver si nécessaire.

**Échéances.** Les rappels J−30 et J−7 apparaissent dans le dossier et sont destinés au formateur. Un document expiré reste disponible tant que son partage est actif. Vous pouvez corriger son échéance dans « Modifier les informations ». La date de fin d’accès est indépendante.

**Organisme.** Dans « Dossiers reçus », ouvrez un dossier partagé avec l’OF courant. Pour une invitation sans compte, ouvrez le lien dans l’e-mail, demandez puis saisissez le code. La session invitée dure 20 minutes. Pour changer d’adresse, le formateur révoque l’accès initial et crée une invitation pour la nouvelle boîte. Aucune commande de dépôt pour un formateur n’est proposée dans ces espaces.

**Suppression.** « Révoquer » coupe l’accès du destinataire. « Supprimer » retire la pièce et ses versions de la base active. Le destinataire garde la maîtrise de ses propres téléchargements.
