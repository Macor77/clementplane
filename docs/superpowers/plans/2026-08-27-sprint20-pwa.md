# Sprint 20 — Clementplane PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformer Clementplane v0.19.6 en PWA installable et maintenable sur mobile, avec installation guidée, état hors connexion et mise à jour contrôlée, sans fonctionnement métier hors ligne.

**Architecture:** `vite-plugin-pwa` génère le manifest et le service worker depuis une configuration testable centralisée dans `pwa.config.js`. Un gestionnaire React global, monté une seule fois, orchestre installation, détection standalone, connectivité et nouvelles versions sans modifier les services Supabase ni les écrans métier.

**Tech Stack:** React 19, Vite 7, vite-plugin-pwa, Workbox (via vite-plugin-pwa), Vitest 3, Playwright 1.55.

**Spec:** `docs/superpowers/specs/2026-08-27-sprint20-pwa-design.md`

## Global Constraints

- Base obligatoire : `Clementplane_v0.19.6_Sprint19.6_Closure.zip`.
- Identité obligatoire : réutiliser les assets Clementplane validés au Sprint 19.6 ; ne pas redessiner le logo.
- Aucune synchronisation métier hors connexion.
- Aucune mise en cache applicative des réponses Supabase comme source de données hors ligne.
- Aucun changement de schéma, RLS ou Edge Function Supabase.
- Installation depuis le navigateur uniquement ; aucune publication App Store / Google Play.
- Mise à jour de version finale : `v0.20.0` uniquement à la clôture du Sprint.
- Roadmap finale : Sprint 20 PWA, Sprint 21 création autonome de missions par le formateur, Sprint 22 synchronisation Google Agenda.

- [ ] **Step 3: implémenter les fonctions pures**

```js
export const INSTALL_HINT_COOLDOWN_MS = 7 * 24 * 60 * 60 * 1000;

export function isIosDevice(navigatorLike = navigator) {
  const ua = navigatorLike?.userAgent || '';
  const platform = navigatorLike?.platform || '';
  const touchPoints = navigatorLike?.maxTouchPoints || 0;
  return /iPad|iPhone|iPod/.test(ua) || (platform === 'MacIntel' && touchPoints > 1);
}

export function isStandalone(windowLike = window, navigatorLike = navigator) {
  return Boolean(
    windowLike?.matchMedia?.('(display-mode: standalone)')?.matches ||
    navigatorLike?.standalone === true,
  );
}

export function shouldShowInstallHint({ installed, dismissedAt, now = Date.now(), cooldownMs = INSTALL_HINT_COOLDOWN_MS }) {
  if (installed) return false;
  if (!dismissedAt) return true;
  return now - dismissedAt >= cooldownMs;
}
```

- [ ] **Step 1: ajouter le composant sans logique métier**

Le composant doit stocker l’événement `beforeinstallprompt`, écouter `appinstalled`, `online`, `offline`, et mémoriser la fermeture de l’aide dans `localStorage` sous `clementplane:pwa-install-dismissed-at`.

```jsx
import { useEffect, useMemo, useState } from 'react';
import { useRegisterSW } from 'virtual:pwa-register/react';
import {
  INSTALL_HINT_COOLDOWN_MS,
  isIosDevice,
  isStandalone,
  shouldShowInstallHint,
} from '../../pwa/pwaEnvironment.js';
import './PwaManager.css';

const DISMISSED_KEY = 'clementplane:pwa-install-dismissed-at';

export default function PwaManager() {
  const [online, setOnline] = useState(() => navigator.onLine);
  const [deferredPrompt, setDeferredPrompt] = useState(null);
  const [dismissedAt, setDismissedAt] = useState(() => Number(localStorage.getItem(DISMISSED_KEY)) || 0);
  const installed = isStandalone(window, navigator);
  const ios = isIosDevice(navigator);

  const {
    needRefresh: [needRefresh, setNeedRefresh],
    updateServiceWorker,
  } = useRegisterSW();

  useEffect(() => {
    const handleOnline = () => setOnline(true);
    const handleOffline = () => setOnline(false);
    const handleInstallPrompt = (event) => {
      event.preventDefault();
      setDeferredPrompt(event);
    };
    const handleInstalled = () => setDeferredPrompt(null);

    window.addEventListener('online', handleOnline);
    window.addEventListener('offline', handleOffline);
    window.addEventListener('beforeinstallprompt', handleInstallPrompt);
    window.addEventListener('appinstalled', handleInstalled);
    return () => {
      window.removeEventListener('online', handleOnline);
      window.removeEventListener('offline', handleOffline);
      window.removeEventListener('beforeinstallprompt', handleInstallPrompt);
      window.removeEventListener('appinstalled', handleInstalled);
    };
  }, []);

  const showInstallHint = useMemo(() => shouldShowInstallHint({
    installed,
    dismissedAt,
    cooldownMs: INSTALL_HINT_COOLDOWN_MS,
  }), [installed, dismissedAt]);

  const dismissInstallHint = () => {
    const value = Date.now();
    localStorage.setItem(DISMISSED_KEY, String(value));
    setDismissedAt(value);
  };

  const install = async () => {
    if (!deferredPrompt) return;
    await deferredPrompt.prompt();
    await deferredPrompt.userChoice;
    setDeferredPrompt(null);
  };

  return (
    <div className="pwa-notices" aria-live="polite">
      {!online && (
        <div className="pwa-notice pwa-notice--offline">
          <strong>Vous êtes hors connexion.</strong>
          <span>Clementplane nécessite une connexion Internet pour accéder aux données et les modifier.</span>
        </div>
      )}

      {needRefresh && (
        <div className="pwa-notice">
          <span>Une nouvelle version de Clementplane est disponible.</span>
          <button type="button" onClick={() => updateServiceWorker(true)}>Mettre à jour</button>
          <button type="button" onClick={() => setNeedRefresh(false)} aria-label="Fermer">×</button>
        </div>
      )}

      {online && showInstallHint && !needRefresh && (deferredPrompt || ios) && (
        <div className="pwa-notice">
          {deferredPrompt ? (
            <>
              <span>Installez Clementplane sur votre écran d’accueil.</span>
              <button type="button" onClick={install}>Installer Clementplane</button>
            </>
          ) : (
            <span>Sur iPhone/iPad : Partager → Sur l’écran d’accueil → Ajouter.</span>
          )}
          <button type="button" onClick={dismissInstallHint} aria-label="Fermer">×</button>
        </div>
      )}
    </div>
  );
}
```
