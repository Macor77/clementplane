# Tutoriels Clementplane

Ce dossier contient les tutoriels utilisateurs illustrés de Clementplane.

Les captures sont réalisées dans l'environnement isolé `documentation-demo`, avec des comptes et des données entièrement fictifs. Elles ne doivent jamais contenir de données issues de la production.

## Organisation

- `formateurs/` : parcours propres aux formateurs ;
- `organismes/` : parcours propres aux organismes de formation ;
- `communs/` : actions communes aux deux profils ;
- `parcours-croises/` : parcours complets Formateur ↔ OF.

Chaque tutoriel regroupera son contenu source, ses captures originales et ses captures annotées afin de permettre sa réutilisation dans l'application, la FAQ, la landing page et des documents d'aide.
