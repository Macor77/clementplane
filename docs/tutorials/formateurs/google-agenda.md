# Retrouver mes missions dans Google Agenda

1. Dans Clementplane, ouvrez les paramètres de votre espace formateur, puis Google Agenda.
2. Choisissez Connecter Google, le compte voulu et autorisez la connexion. Sur mobile, restez dans le même navigateur.
3. Attendez une dernière synchronisation réussie, puis ouvrez le calendrier « Prénom Nom — Clementplane ».
4. Modifiez vos missions dans Clementplane : les copies Google sont ensuite actualisées, même application fermée.
5. Activez séparément rémunération ou notes uniquement si vous souhaitez les copier. Elles sont exclues par défaut.

Le calendrier a son propre partage Google. Partager l’agenda principal ne le partage pas automatiquement. Pour ne montrer que les créneaux occupés aux OF, utilisez les disponibilités seules ; des droits avancés peuvent révéler les détails privés. Déconnecter arrête les mises à jour mais conserve les copies. Reconnectez le même compte pour reprendre.
